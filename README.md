# Isabella Floristería

Sitio web de Isabella Floristería, una floristería de Atlixco, Puebla. Presenta el negocio, las flores disponibles y de temporada, trabajos florales, experiencias de clientes y opciones para solicitar información o cotizaciones.

## Estado del proyecto

El sitio ya está en producción y se actualiza constantemente. El proyecto seguirá creciendo de acuerdo con las necesidades de la floristería, incorporando nuevas funciones y mejoras apoyadas en tecnologías web.

## Tecnologías

- React y TypeScript para la interfaz.
- Vite para la compilación del sitio.
- Supabase para las funciones que requieren datos.
- Vercel para el despliegue en producción.
